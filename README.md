# Java JDBC Budget Tracker

A console-based monthly budget management system built using Java, JDBC, and MySQL.

## Features

- Opening balance onboarding
- Track received and spent money
- Prevent negative balance
- Planning module with priorities
- Monthly report
- Exit-time cleanup (keep/delete data)
- Console table display
- MySQL backend

## ## Tech Stack

- **Languages:** Java  
- **Database:** MySQL  
- **Tools:** Git, GitHub, NetBeans  
- **Concepts:** OOP, JDBC, Basic Backend Architecture  

## How to Run

1. Create database using db.sql
2. Update DBConnection.java with your MySQL credentials
3. Compile:

javac *.java

4. Run:

java Main
